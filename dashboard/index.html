Reels loop

What each scheduled run of the @getdivvyupp loop did on a given day. Times are New York time.

    Each run writes runlog/<date>/<run>.json in DivvyUpp/divvyupp-media (format in PLAYBOOK.md, "Run log"). A run with no record either didn't start or couldn't save it. The page can lag GitHub by a few minutes.
